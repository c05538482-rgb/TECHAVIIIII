TECHAVI - TEMIZ REPO KURULUMU

1) GitHub'da YENI ve BOS bir repository olustur.
2) Bu ZIP'i ac.
3) ZIP'in icindeki DOSYALARIN TAMAMINI GitHub reposunun ana sayfasina yukle.
   Ozel olarak bir klasorun icine koyma.
4) Commit changes yap.
5) Render'da yeni GitHub reposunu bagla.
6) Deploy bitince https://techav1.onrender.com/ adresini ac.

Amazon Türkiye ana sayfada magaza karti olarak dahildir.
Bright Data Amazon test sayfasi da dahildir: /brightdata-test

Not: API anahtarlarini ZIP'e koyma. Render Environment Variables icinde kalmali.
