TECHAVIII - HIZLI KADEMELI ARAMA GUNCELLEMESI
================================================

Bu paket mevcut GitHub projenin tamamini otomatik indirip hizli arama surumunu olusturur.

NE DEGISTIRILDI?
- Magazalar yine paralel aranir.
- Hicbir yeni ReefAPI sorgusu eklenmez.
- Kredi tuketimi artmaz.
- Hizli cevap veren magaza sonucu hemen ekrana gelir.
- Yavas bir magaza diger magazalari bekletmez.
- Amazon da ayni akis icinde gelir.
- Eski /api/search endpointi korunur.

KULLANIM
1. Bu ZIP'i ac.
2. HIZLI_ARAMA_KUR.bat dosyasini calistir.
3. Script GitHub'daki guncel TECHAVIII reposunu indirir.
4. Gerekli server.js ve public/app.js degisikliklerini otomatik uygular.
5. TECHAVIII_HIZLI_ARAMA klasoru olusur.
6. Bu klasoru ZIP'leyip GitHub'a yukleyebilir veya Render'a baglayabilirsin.

NOT:
Bu paket API anahtarlarini icermez. REEF_API_KEY ve diger gizli degiskenler Render Environment Variables'ta kalmalidir.
