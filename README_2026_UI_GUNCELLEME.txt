TechAvı UI güncellemesi

- Mağaza kartları arama alanının sol altında, daha kompakt düzende konumlandırıldı.
- Ana menüdeki Fırsatlar, Fiyat Düşüşleri ve Dip Fiyatlar artık çalışıyor.
- Fırsatlar: en az %10 indirim görünen ürünleri indirim oranına göre sıralar.
- Fiyat Düşüşleri: mevcut fiyatı listelenen/orijinal fiyattan düşük ürünleri gösterir.
- Dip Fiyatlar: mevcut fiyatı en düşük ürünleri üstte gösterir.
- Yeni arama yapıldığında görünüm otomatik olarak normal sonuçlara döner.
- API çağrı mantığı değiştirilmedi; mevcut hızlı mağaza bazlı arama yapısı korunmuştur.
